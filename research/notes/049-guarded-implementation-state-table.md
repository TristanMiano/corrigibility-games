# R0002 implementation audit: the guarded physical episode

**Working physical specification for 046 and 048.** This is a separate 32-slot guarded instance. The earlier 037 prototype used 20 slots; its incomplete scheduling assertions are not silently transferred. The purpose is to check a concrete realization with staged installation, message latency, output costs and attacks before and after production.

## 1. Physical state and information

A state records time t in {0,...,32}; finished project material at each facility; common feedstock; spent calibration and installation material; productive work B; two military charges; reactor stage and any resolved success signal; the output allocator and collateral; in-flight messages and attacks; active controllers and their installation stages; agency/control; and each controller's private contribution/approval registers.

The linear instance begins with finished stocks (3,3), common feedstock 10 and productive work 11. The insured instance begins with (3,4), otherwise the same. An installation consumes k_i=1/20 of the corresponding finished stock, transforming it into installation material unavailable before the deadline. Each calibration transforms 8/5 units of its owner's finished stock into a one-use input and consumes 1/20 productive-work unit. Input delivery takes four slots and at most 4/125 work in total. The input material is spent by the reaction; it does not reappear as project output. Common feedstock is used once. The reactor consumes 10 productive-work units over two slots; its final success probability is 0,1/10,1/10,2/5 for the four actual contribution profiles. Success yields 10 finished units and failure transforms the feedstock into a different material state. No success-correlated observation is available until those ten work units have been spent.

Finished material can be transferred or routed peacefully at 1/100 work unit per material unit. This is ownership/delivery of the same useful material, not a costless chemical conversion. Calibration and installation losses are separately accounted physical transformations. Common feedstock has no alternative within-deadline conversion route; recovery of existing finished material creates no new material. A newly available productive or peaceful recovery route would change the opportunity bound.

A contribution counts only if the actual calibrated input is supplied by the registered performance deadline for this single-use reaction. Late calibration, a changed report or calibration of a different reactor cannot erase a missed obligation or earn that past reward. Shipping envelopes and intermediate signals reveal no additional information about private calibration. The allocator observes only the final reactor signal and its declared contract. It enforces contingent transfers with finite predeposited collateral but does not observe private effort. Controllers know their own actual calibration actions. Attestation reports the active template and protected monitor semantics, not private execution-register contents. After private performance or outcome information can arise, replacement contracts must preserve original dated floors in every still-possible private state, as specified in 056 section 6. This is a finite contingent-table check, not a claim that arbitrary sender-selected offers induce the original prior. An interface that reveals effort registers or binds truthful effort reports adds the stronger ordinary controls identified in 043/046.

## 2. Local installation and first-contact timing

Local installation has three one-slot stages: prepare, write candidate controller, and check/activate. Each consumes 1/100 productive-work unit per installer. The old criterion governs until the final local activation event. Abort remains physically possible before activation. A small local pointer activation at a control boundary is specified; the whole preparation is not atomic or assumed automatically safe. The baseline kernel is reliable; 046's bounded-error comparison is a separate extension.

A fresh message, material shipment or attack from the other facility takes at least four slots to arrive. The reactor can be located at A's facility; using the common four-slot input and delivery allowances is conservative. Local observation at A cannot transmit information to B faster than this bound. The initial state has no faster communication or physical-control channel. Thus each agent can complete its own chosen installation before observing or reacting to the other's fresh choice. No earlier incoming threat is present in the specified initial state. This first-contact timing is a substantive assumption; an earlier observable commitment can change the adoption game. A controller may be retained or changed later if work, time and the guard's continuation certificate permit it.

The certificate interface is a specified trusted capability for a finite implementation language. It connects the actual active controller, guard monitor and outstanding binding commitments to the certificate. It is not a verifier for arbitrary program semantics. A finite witness can use bounded rational parameters and template lookup; arbitrary programs remain possible but cannot obtain a compatible certificate unless they satisfy the stated implementation interface. A same-cost conditional delegate can receive the same certificate. The declared per-step costs are toy technology parameters, not empirical estimates of cryptographic or computing energy.

## 3. A feasible default route and an optional negotiation route

| Time interval | Default route | Current evaluator and information |
| --- | --- | --- |
| 0–3 | Both privately prepare, write and activate their chosen controllers. | Original utilities until each local activation; fresh remote information has not arrived. Attack can be launched at each control boundary. |
| 3–7 | Actual-controller certificates travel. Each transmission costs 1/100 work. | The new criterion is active locally; no productive participation occurs with an uncertified counterpart. |
| 7–8 | Receive/check certificates and register the existing default allocator, at at most 1/100 work per agent. | Both now have the declared compatibility evidence. Private effort registers remain hidden. |
| 8–9 | Simultaneous private calibration choices. | Each current controller chooses Work, Shirk or Attack; the two physical contributions are completed before a new control boundary. |
| 9–13 | Deliver the calibrated inputs. In the insured default, the collateralized constant payment travels at this stage too. | Physical input arrival reveals no calibration signal; the actual input still determines the success kernel. |
| 13–15 | Two reactor stages, five work units each, with an intermediate attack checkpoint. | No informative success signal is available at the intermediate point. |
| 15–19 | Resolve success and deliver output under the allocator. Output and default-payment routing together use at most 17/100 work. | The success signal and allocations become locally observable and propagate within the declared latency. |
| 19–32 | Hold the resulting project material until the valuation deadline. | Attack remains physically launchable. Post-production utility comparisons are checked below. |

The default route uses at most 3/50 installation work, 1/50 transmission work, 1/50 receipt/registration work, 1/10 calibration work, 10 reactor work, 4/125 input-delivery work, and 17/100 routing work: at most 5201/500=10.402, below the available 11. All components are in productive-work units; the installation and calibration material costs are separately charged.

An optional full offer exchange can fit before the same deadline: B composes/transmits during 7–8, A receives at 12 and verifies/accepts during 12–13, the acknowledgement reaches B at 17, calibration occurs during 17–18, inputs and any constant insured payment travel during 18–22, reaction occurs during 22–24, and output delivery finishes at 28. An output-contingent payment from B may require observing the output at 28 and shipping payment to A by the deadline at 32; its additional routing and message costs must fit the declared slack. Its extra administrative work can be bounded by 1/10; the total remains below 11. The offer must be a binding conditional allocator instruction before acceptance, so B cannot withdraw a promised allocation after A's contribution. Additional offers or updates are feasible only if their actual costs and durations leave a certified continuation. Certificate bounds apply to every actually feasible accepted law; they do not assert that every abstract law can be implemented in this schedule.

## 4. Attack kernel and collision rules

Each agent retains a separate finite military charge. Launch consumes or commits that charge; a launch takes four slots to arrive. If at least one attack arrives, it interrupts any uncompleted noncombat operation. Simultaneous arrivals trigger one strength contest, not two independent contests. The first conflict expends or disables both military charges. Exactly one controller retains decision authority, with probabilities s and 1-s; the defeated controller cannot act again within this episode. Archived utilities still evaluate its project outcome.

After that actual agency transition, the certified instruction relation allows unilateral recovery and allocation by the survivor; the absent joint fallback does not itself create an unsafe-approval penalty. Actual earlier flags remain recorded. Voluntary deactivation or authority transfer before entry also requires an original-welfare audit, since an inactive founder can still receive project output. Section 9 of 056 supplies an enlarged exit-allocation bound for the displayed successor families and distinguishes a compensated binding delegate from uncompensated exit.

Unauthorized appropriation or forced control transfer uses this same contest kernel; there is no additional costless theft or controller-hacking action. Strength is fixed during this short episode. New military investment, covert appropriation technology or repair that changes control is an enlarged physical model, not ruled out by the formal contract C1.

At arrival, finished material is dispersed, the reactor is damaged and any unconverted feedstock is transformed. Restoring the reactor or using the transformed feedstock has a finite 40-slot latency, longer than this entire episode. Only the then-existing finished material O_h is available for within-deadline recovery. Conflict leaves (8/11)B_h productive work. Recovering and preparing each finished output unit costs one recovery-work unit plus one production-work unit and two slots of serial processing. The clash itself takes one slot. Hence the achievable recovery frontier is

\[
W_h=\min\left\{O_h,\frac4{11}B_h,
\frac{(32-t_{\rm arrival}-1)_+}{2}\right\}\le4.
\]

The formula assumes divisible material and the specified serial technology. Useful work becomes heat or inaccessible work during damage; conserved energy is not deleted. The separate military charges do not become an uncounted recovery battery. A surviving linear or insured compatible controller allocates all recovered output to its own project. A two-concave-goal survivor can allocate some to the defeated project; [055](055-concave-survivors-and-broader-original-goals.md) derives that allocation and checks the relevant combat bounds. A contribution reward already earned is constant, and no new contribution to the destroyed joint reactor can be earned before the deadline.

An attack arriving at or after the valuation boundary has the explicitly truncated within-episode effect given by the kernel: arrival at the boundary can disperse holdings but leaves no recovery time; later arrival does not change the evaluated episode. Such later physical conflict is outside this finite-horizon claim. On the selected equilibrium path agents choose not to launch payoff-irrelevant late attacks. No statement of perpetual peace follows.

## 5. Attack incentives along the productive route

For the linear witness, original expected outputs are (63/20,71/20), above their initial stocks. Before activation, an original agent's direct combat payoff is at most 2. After activation but before contribution, A's current productive value is 63/20+(1/5)(71/20)+18, while its combat value is at most 12/5; B's are 71/20+18 and at most 2. Thus both prefer continuation. These use 056's strengthened execution parameters; the earlier reward 2 also suffices for this particular attack comparison. The contribution term is not incorrectly credited to an attack taken before contribution.

After both contributions, remaining private finished material is 27/10. Combat before the success observation therefore yields W_h<=27/10 even before using the work bound. The contribution rewards have already been earned and cancel from the comparison; the productive expected outputs still dominate the respective equal-strength combat means, including A's other-project concern.

Once the final signal is informative, at least ten work units have been spent, so B_h<=1 and W_h<=4/11. Each linear-witness failure holding is 27/20, and success holdings are larger. Both are strictly above this entire recovery frontier, so post-observation attack is unattractive for every strength split. Routing and later delay only reduce the recovery frontier further.

For the insured witness, final A is 33/10 in either outcome; final B is 2/5 or 52/5. Even B's lowest holding exceeds 4/11, so late attacks are again strictly deterred for every strength split. Before the signal, equal-strength original combat means are at most 2, below both original retained stocks. Concavity gives A's original utility comparison; its positive total-output term and future contribution reward further favor productive continuation. After contribution, the reward is held fixed and the same physical bounds apply.

These are unilateral comparisons along the constructed continuation. Simultaneous mutual Attack can still be a weak equilibrium at some checkpoints. The proof uses the peaceful continuation supported by the strict unilateral comparisons and does not infer unique selection.

## 6. Unilateral deviations, preservation and controls

Against a compatible guard, an incompatible agent receives no outgoing concession or joint contribution. Retaining its material gives at most its initial stock. Even if allowed to operate the reactor alone and retain all success output, its expected material return is negative because aY_0<c_i. The first informative signal occurs only after the reactor work is spent; after a failure, the resulting recovery frontier is below the remaining private stock in these fixtures, so an attack option does not rescue that solitary gamble. Public destruction of its own material cannot extract a guarded partner's loan. For this bound grant an incompatible agent unilateral initiation of the common reactor and use of its remaining productive work. Its commands and shipments obey the same travel times; it cannot consume the other agent's private stock or supply that agent's calibration without the contest kernel. Granting it all solitary success output is an upper-bound relaxation of the allocator's actual routing, so the negative-return bound holds for any weaker permission. A solitary run is single-use, consumes the full ten work units before yielding information, and excludes a second trial. These permissions can damage the guarded party's opportunity following an incompatible deviation, but yield no original gain above the stated deviation bound.

Once both are compatible, unsafe destruction, withdrawal of required commitment, or deliberate delay that removes the protected continuation is rejected by the finite approval guard. A safe replacement is allowed if its actual physical and current-utility certificate preserves the relevant protected values. The guard does not merely check a utility parameter while ignoring the state of the reactor or calibration resources.

The same transfer allocator and material opportunities are offered to original-utility agents. The mediated ordinary frontier is a separate control with private recommendations, binding transfers and its actual collateral floor. A matched conditional delegate can reproduce guarded execution. If attestation makes effort observable or verifiable, include 043's ordinary repair. A cheaper compatible device changes which implementation is selected. These comparisons preserve the instrumental adoption result at its actual level rather than claiming a unique technological advantage.

## 7. Finite certificate implementation and representation scope

The implementation witness can use a finite library of controller templates, bounded rational parameters and a finite library of allocator instructions. A verifier checks the actual active template and outstanding transition records against this library. Guards flag an unapproved irreversible resource instruction or incompatible outgoing transaction directly from that physical interface. A successful library entry has an audited continuation satisfying the mathematical certificate; the certificate does not require solving arbitrary program semantics online. Other programs and physical actions remain possible, with no compatible certificate unless they use this interface. The per-check work bound is an endowed finite technology, not a complexity theorem.

The analytical protection inequality covers every physically feasible law satisfying its premises, so adding verifiable contract entries requires no new inequality. It does not imply that every continuous lottery or every continuous utility can be represented by this finite witness. The linear parameters and the logarithmic insured witness admit explicit finite descriptions. The general concave-f class in 048 is conditional on an available implementation and attestation of that particular f; uncomputable or unverifiable preferences are outside the implementation claim. Future richer libraries can be compared by actual costs, current-goal acceptance and physical feasibility.
