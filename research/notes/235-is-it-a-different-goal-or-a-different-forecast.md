# Is it a different goal or a different forecast?

A partner can answer every tested choice consistently with the agreed goal and still attach different terminal importance to physical states. A difference in its beliefs can exactly offset the difference in values. A new signal about the *same* state can leave this ambiguity intact. The useful additional experiment changes how the state is produced or independently anchors what a reward is worth across states.

## Two descriptions with identical choices

Let s be a physical state with positive subjective probability p_s. A plan specifies an objective lottery f_s over stocks in each state. The evaluator assigns the plan value Σ_s p_s E[u_s(f_s)]. State-dependent terminal utilities allow the same amount to matter differently in distinct production conditions. For any other full-support q, set

    u'_s(x)=(p_s/q_s)u_s(x)+c_s.

The complete ranking over these plans is identical under (q,u') and (p,u). The additive term is independent of every plan. On a common observation with state likelihoods l_s the posterior weighted utilities are proportional up to an action-independent term: after normalizing by Σp_s l_s or Σq_s l_s respectively, the action-dependent numerator is always Σp_s l_s E[u_s(f_s)]. The argument applies to a sequence of such observations and to a whole contingent strategy with its chosen actions. Observing choices after the state is fully revealed gives only the within-state ordering, where the positive scaling has no effect. An ungrounded report of the agent's stated probabilities can of course differ without establishing which report is accurate.

If the agreed object is only the induced ordering of the observable plans, these descriptions agree on it. If the contract specifies terminal preferences over *objective lotteries on named state–outcome pairs*, scaling each state differently can reverse an ordering there. The ambiguity is consequential when future work can change the state-generating mechanism.

For example, the target equally values own plus partner stock in two lines, with natural-arrival probabilities (.5,.5). A second controller expects arrivals (.8,.2) and values those same stocks at 5/8 times as much on line one and 5/2 times as much on line two. Both controllers can be genuine changes from own stock alone. On every naturally arrived conditional act they agree. Now the firms can let a witnessed fair router *assign* an otherwise identical batch to either physical line; both know the assignment probabilities. A first preparation yields one extra terminal unit on line one alone. A second yields half a unit on line two alone. The target prefers the first (.5 against .25); the alternative prefers the second (.3125 against .625). Fresh news about a pending natural arrival and taking control of which arrival occurs have different evidential powers. If the state is uncontrollable weather, this particular intervention is unavailable.

## Why asking for a probability can repeat the same evidence

Offer a forecast prize by drawing a standard prize B rather than A with probability 1−(r−s)² for a report r about binary state s. Let v_s=u_s(B)−u_s(A)>0. A sincere expected-utility maximizer reports

    r* = p v₁/[p v₁+(1−p)v₀].

This minimizes p v₁(1−r)²+(1−p)v₀r². If the same physical prize has independently verified equal utility increments in the two states, r*=p. If v₁/v₀ belongs only to [l,h], then posterior odds for the belief being elicited satisfy odds(r*)/h ≤ odds(p) ≤ odds(r*)/l. For r*=.5 and [l,h]=[.5,2], the compatible p ranges from one third to two thirds. In the two-line example the scaled utilities and changed beliefs also give the same prize report as the target. Binarizing the payment removes curvature over money within the lottery but still needs a cross-state prize anchor.

Future access can independently distort the report. If the prize has stake multiplier λ in utility increments and the continuation benefit from changing the report ranges over at most D in current expected utility units, any optimum lies within sqrt(D/[λ(pv₁+(1−p)v₀)]) of r*. This follows by completing the square and comparing against sending r*. A known anchor and sufficient stakes bound both sources of uncertainty; a report made more lucrative by earning the main contract needs its additional incentive assessed.

## A buyer can still commit under unresolved beliefs

Suppose the two witnessed post-installation possibilities above have probabilities .6 and .4. The customer's later work uses the fair router; the first preparation gains it three over return, and the second loses one. Its expected gain is 1.4 even if previous observations of natural arrivals cannot tell which controller was installed. The two preparations can allocate the extra stocks to different projects the buyer values differently. A separately funded and genuinely diagnostic pilot on the fair router is worth at most .4 over blind release for this decision: it avoids the .4 chance of a one-unit loss. If it costs .2, both can afford to use it when the original supplier earns at least one on an accepted order, pays .2 to run the witnessed procedure, and cannot obtain the same admission by presenting a retained controller. The comparison presumes that the observed pilot choice really follows the active preference. If the rival can imitate the target choice just to collect a larger future order, the assurance must instead satisfy the incentive bound above or rely on a separate physical readout. A safe stock return above the expected recovery from a destructive contest preserves the outside option until final release.

**Naturality and reach.** Forecasts can differ across sites and a unit of output can matter more during shortages. A contract using line-specific production choices can therefore entangle learning about beliefs and learning about a terminal goal. A purchaser that controls a genuinely randomized routing opportunity can buy a discriminating test where a remote observer cannot. Shared state-independent utility increments, a credible randomizer and stable interpretation of the state labels are demanding premises. An ordinary policy can serve every currently tested case even while the structural question remains open. The sibling grounds one reference prize's value in both states. The higher question asks what a bargain needs to specify about future interventions before agreement on today's choices is enough.
